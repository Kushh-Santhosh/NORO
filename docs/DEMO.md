# Judge mode

Every demo name, organization, ward, asset, issue, coordinate, metric, and event is fictional. The app is **SIMULATED · PROPOSED, NOT ADOPTED**.

## Personas

- Citizen: Asha Rao
- Manager: Meera Nair, Civic Operations Manager
- Contractor: Imran Khan, CivicWorks Electrical Services · Electrical & Lighting
- Independent Verifier: Ravi Menon
- Public: unauthenticated, read-only map and ledger

Manager’s internal contractor directory includes organizations for electrical, plumbing, civil/footpath, parks, and sanitation. Those organizations are not separate demo accounts. Imran sees only assignments to his demo account.

## Flows

1. Open `/demo` and enter the manager workspace. Open a verified issue, review the real map, select an eligible directory organization, and assign.
2. Sign out and enter Imran’s contractor workspace. Accept, start, add repair notes and photo evidence, and claim the repair. The status becomes Verification pending.
3. Sign out and enter Ravi’s verifier workspace. Review the repair record, complete the asset-category checklist, declare no conflict, add verifier evidence, then pass or fail. Pass closes; fail reopens the same issue.
4. Visit `/public-ledger`, `/assets`, and `/map`. Public views omit personal identities and private notes.
5. As Asha, start a report from a map pin, select a nearby registry asset or “This asset isn’t listed,” then add a category-specific issue and optional evidence.

Demo changes are stored in this browser profile. Clear the site’s local storage to restore original sample data.
